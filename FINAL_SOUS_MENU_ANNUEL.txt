🔧 SOLUTION APPLIQUÉE
═══════════════════════════════════════════════════════════════════════════

Au lieu de recalculer les moyennes et coefficients, on utilise maintenant 
la MÊME méthode que le bulletin annuel :

✅ preparerDonneesBulletinAnnuel($eleve, $periodes)

Cette méthode retourne :
• moyennesParPeriode (T1, T2, T3)
• moyenneAnnuelle
• moyennesAnnuellesParMatiere (par matière)
• notesParPeriode (pour récupérer les coefficients)

═══════════════════════════════════════════════════════════════════════════
📊 MODIFICATIONS APPLIQUÉES
═══════════════════════════════════════════════════════════════════════════

1️⃣ MÉTHODE annuelResultats() :
   ────────────────────────────
   AVANT : Calculait les moyennes avec Note::calculerMoyenneGenerale()
   APRÈS : Utilise preparerDonneesBulletinAnnuel()
   
   Code :
   ```php
   $donneesAnnuelles = $this->preparerDonneesBulletinAnnuel($eleve, $periodes);
   $moyenneT1 = $donneesAnnuelles['moyennesParPeriode']['trimestre1'] ?? null;
   $moyenneT2 = $donneesAnnuelles['moyennesParPeriode']['trimestre2'] ?? null;
   $moyenneT3 = $donneesAnnuelles['moyennesParPeriode']['trimestre3'] ?? null;
   $moyenneAnnuelle = $donneesAnnuelles['moyenneAnnuelle'] ?? null;
   ```

2️⃣ MÉTHODE annuelDetailNotesImprimer() :
   ─────────────────────────────────────
   AVANT : Calculait les moyennes par matière avec construireMoyennesAnnuellesParMatiere()
   APRÈS : Utilise preparerDonneesBulletinAnnuel() et récupère les coefficients des notes
   
   Code :
   ```php
   $donneesAnnuelles = $this->preparerDonneesBulletinAnnuel($eleve, $periodes);
   $moyennesAnnuellesParMatiere = $donneesAnnuelles['moyennesAnnuellesParMatiere'];
   
   // Récupère le coefficient depuis les notes (comme le bulletin)
   foreach ($periodes as $periode) {
       $notePeriode = $donneesAnnuelles['notesParPeriode'][$periode]
           ->where('matiere_id', $matiere->id)->first();
       if ($notePeriode && $notePeriode->coefficient) {
           $coefficient = $notePeriode->coefficient;
           break;
       }
   }
   ```
