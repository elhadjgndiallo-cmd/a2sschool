Pour vérifier que le bulletin couvre toute la page :

1. Ouvrir un bulletin annuel
2. Appuyer sur Ctrl+P (Windows) ou Cmd+P (Mac)
3. Vérifier l'aperçu PDF :
   ✓ Le cadre doit aller jusqu'en bas de la page
   ✓ Pas d'espace blanc visible en bas
   ✓ Les marges doivent être uniformes

4. Enregistrer le PDF et vérifier :
   ✓ Ouvrir le PDF dans un lecteur
   ✓ Vérifier que le contenu va jusqu'en bas
   ✓ Vérifier la taille du fichier PDF (devrait être A4)

Si le bulletin ne couvre toujours pas toute la page :

1. VIDER LE CACHE DU NAVIGATEUR
   • Chrome : Ctrl+Shift+Delete → Cocher "Images et fichiers"
   • Firefox : Ctrl+Shift+Delete → Cocher "Cache"
   • Edge : Ctrl+Shift+Delete → Cocher "Images et fichiers"

2. FORCER LE RECHARGEMENT
   • Appuyer sur Ctrl+F5 sur la page du bulletin
   • Ou Shift+F5 pour un rechargement complet

3. VÉRIFIER LES PARAMÈTRES D'IMPRESSION
   • Format : A4 (pas Letter)
   • Échelle : 100%
   • Marges : Par défaut

4. TESTER DANS UN AUTRE NAVIGATEUR
   • Chrome est généralement le plus fiable pour l'impression

5. VÉRIFIER LE FICHIER CSS
   • Ouvrir : public/css/print-bulletin.css
   • Vérifier que @page margin est bien : 0.3cm 0.5cm 0.3cm 0.5cm
