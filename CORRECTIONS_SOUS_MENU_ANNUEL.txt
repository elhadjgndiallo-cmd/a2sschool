📊 DÉTAILS TECHNIQUES
═══════════════════════════════════════════════════════════════════════════

CALCUL DES MOYENNES (identique au bulletin annuel) :

1. MOYENNE TRIMESTRIELLE :
   Note::calculerMoyenneGenerale($eleve->id, 'trimestre_1')
   → Paramètre : 'trimestre_1', 'trimestre_2', 'trimestre_3' (avec underscore)

2. MOYENNE ANNUELLE GLOBALE :
   $moyennesParPeriode = [
       'trimestre_1' => $moyenneT1,
       'trimestre_2' => $moyenneT2,
       'trimestre_3' => $moyenneT3
   ];
   Note::calculerMoyenneGeneraleAnnuelle($moyennesParPeriode)

3. MOYENNES ANNUELLES PAR MATIÈRE :
   $periodes = ['trimestre_1', 'trimestre_2', 'trimestre_3'];
   $notesParPeriode = [];
   
   foreach ($periodes as $periode) {
       $notes = $eleve->notes()
           ->where('periode', $periode)
           ->with('matiere')
           ->get();
       $notesParPeriode[$periode] = $notes;
   }
   
   $moyennesAnnuellesParMatiere = Note::construireMoyennesAnnuellesParMatiere(
       $notesParPeriode, 
       $periodes
   );

CLASSEMENT (RANGS) :
- Rang T1 : Basé sur moyenne T1 décroissante
- Rang T2 : Basé sur moyenne T2 décroissante
- Rang Annuel : Basé sur moyenne annuelle décroissante
- Les élèves sans notes ne sont pas classés (affichent "-")
